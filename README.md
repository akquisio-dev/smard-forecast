# smard-forecast

Probabilistic day-ahead to 6-day forecasts (p10, p50, p90) of German solar, onshore wind and
offshore wind generation, built for the
[smard-mcp](https://github.com/akquisio-dev/smard-mcp) tool `forecast_renewables`.

Status: planning. See [docs/PLAN.md](docs/PLAN.md) (German).

## Data sources

- Electricity data: Bundesnetzagentur | SMARD.de (CC BY 4.0)
- Weather data: Open-Meteo.com (CC BY 4.0), models of the Deutscher Wetterdienst (DWD)
